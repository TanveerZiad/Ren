# Ren Overview

Ren is a local-first personal knowledge management companion designed with a strict rule: "Never make me organize anything."

## Core Workflow
Drop a PDF, TXT, or Markdown file into the inbox. Ren keeps a safe managed copy of your original file, extracts its key concepts into small source-backed knowledge cards, and schedules them for spaced review.

## Spaced Repetition and Retention
Ren maintains an automated remember queue. Knowledge cards you haven't seen in a while resurface based on a progressive spaced-repetition interval (1, 3, 7, 14, and 30 days). When you review a knowledge card, Ren updates its review count and schedules the next revisit date so you retain key insights over time without manual scheduling.

## Local Storage and Privacy
All files, SQLite database records, and vector embeddings are stored completely locally in your application data directory. No cloud account or external database is required.
