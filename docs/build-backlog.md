# Sustainable backlog

## Validate the small loop

- [ ] Import 20 genuinely messy PDF/TXT/MD files.
- [ ] Archive weak cards; record whether the remaining cards are useful.
- [ ] Use the Remember queue for two weeks and adjust the review intervals only if they feel wrong.
- [ ] Improve PDF page anchors so a card opens at the relevant page.
- [ ] Package the local app for Windows only after the loop is personally useful.

## Only after that works

- [ ] Add an optional LLM to improve extraction quality.
- [ ] Add semantic search and evaluate it against a saved set of questions.
- [ ] Choose one advanced feature: Context Packs, stale-card detection, or contradiction candidates.
